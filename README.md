# Malviya Public School

A modern, responsive, high-performance School Web Application built with **React 19**, **Vite**, **Tailwind CSS v4**, **Framer Motion**, and **Lucide Icons**.

## Features
- **Exact UI/UX Replication**: Matched 1:1 with reference mobile and desktop designs.
- **Pure Light Mode & Dark Mode Toggle**: Smooth theme switching across all components.
- **Top Announcement Marquee**: Dynamic scrolling updates on CBSE results, sports events, and admission alerts.
- **Left Navigation Drawer**: Search, expandable accordions, quick links, social media channels, and direct Portal Access Login.
- **Animated Floating Dock**: Glassmorphism blur, spring-animated pill indicator, and fast navigation.
- **NumberTicker Counter Animation**: Dynamic smooth easing for campus metrics (1000+ Happy Students, 50+ Faculty, 25+ Years of Trust).
- **Interactive Modals**: Dedicated views for Academics, About Us, Admissions, Campus Life, Gallery, News & Events, and Contact Us.
- **Prospectus Download**: Simulated official school prospectus download.

## Getting Started
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
